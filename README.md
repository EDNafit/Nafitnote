# سایت بررسی

سایت ایستا با HTML، CSS و JavaScript برای انتشار در GitHub Pages.

تعداد پرسش‌وپاسخ‌های استخراج‌شده: 297

## فایل‌ها
- `index.html`: ساختار صفحه و عنوان «بررسی»
- `style.css`: طراحی راست‌چین و واکنش‌گرا
- `script.js`: نمایش پرسش‌ها و انیمیشن دکمه «اعمال»
- `questions.js`: متن پرسش‌ها و پاسخ‌ها

## انتشار
1. فایل‌های این ZIP را در ریشه مخزن GitHub قرار دهید.
2. وارد **Settings → Pages** شوید.
3. در **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کنید.
4. شاخه `main` و پوشه `/(root)` را انتخاب و ذخیره کنید.
5. آدرس سایت پس از انتشار در همان صفحه نمایش داده می‌شود.

نیازی به نصب کتابخانه یا اجرای build نیست.
