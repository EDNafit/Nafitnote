# وب‌سایت پرسش‌ها و پاسخ‌ها

نسخه ساده و مینیمال برای انتشار در GitHub Pages.

## فایل‌ها
- `index.html`: ساختار صفحه
- `style.css`: ظاهر و حالت محو شدن
- `script.js`: رفتار دکمه و نمایش محتوا
- `questions.json`: محتوای استخراج‌شده از فایل یادداشت

## انتشار در GitHub Pages
1. هر چهار فایل اصلی (`index.html`، `style.css`، `script.js` و `questions.json`) را در ریشه یک مخزن GitHub قرار دهید.
2. در مخزن، وارد **Settings → Pages** شوید.
3. در بخش **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کنید.
4. شاخه `main` و پوشه `/(root)` را انتخاب و ذخیره کنید.
5. پس از چند دقیقه، نشانی سایت در همان بخش نمایش داده می‌شود.

دکمه بالای صفحه ثابت است و هنگام اسکرول هم دیده می‌شود. با آن، محتوای پرسش‌ها و پاسخ‌ها به‌آرامی محو یا دوباره ظاهر می‌شود.

تعداد جفت‌های استخراج‌شده از فایل اصلی: 200
